# ربط الدومين بـ Cloudflare

**الحالة (2026-11-11):** مربوط وشغال. الـ DNS على Cloudflare، و`@` برتقالي، و`www` CNAME برتقالي بيتبع `@`، و`maps` رمادي على السيرفر التاني، وSPF فيه السيرفرين. التشفير **Full (strict)**، وAlways Use HTTPS شغالة، وأقل نسخة TLS 1.2. صور الخريطة بتتخزن في Cloudflare لوحدها (`cf-cache-status: HIT`). الـ token في `.access/cloudflare-token.txt` وعلى السيرفر التاني بس في `/etc/mylawyer/cloudflare.env`. **فاضل:** قفل 80 و443 على السيرفرين إلا لـ Cloudflare (القسم 3).

## 1. هنستفيد إيه
| الفايدة | معناها ببساطة |
|---|---|
| السرعة | صور الخريطة وملفات الموقع واللوحة بتتخزن في سيرفرات Cloudflare القريبة من مصر، بدل ما تيجي من ألمانيا كل مرة |
| الحماية من الهجمات | أي هجوم بيحاول يوقّع السيرفر بكمية طلبات كبيرة بيقف عند Cloudflare قبل ما يوصلنا (مجاني) |
| إخفاء السيرفر | الناس بتشوف عنوان Cloudflare، مش عنوان السيرفر الحقيقي، فصعب حد يهاجمه مباشرة |
| التحويل لو السيرفر وقع | أمر التحويل على السيرفر التاني بيغيّر الدومين بنفسه في ثواني، بدل تغيير يدوي في Hostinger ياخد 5 دقايق |
| حماية من البرامج المؤذية | قواعد جاهزة بتمنع محاولات الاختراق المعروفة (مجاني) |
| شهادة الأمان | Cloudflare بيدّي شهادة https للناس، ومعاها شهادتنا على السيرفر |

كل ده في الخطة **المجانية**. مفيش حاجة محتاجة دفع دلوقتي.

## 2. الخطوات (حوالي 20 دقيقة، والموقع ما بيقفش)
1. ادخل `https://dash.cloudflare.com/sign-up` واعمل حساب بإيميلك.
2. اضغط **Add a domain** واكتب `my-lawyer.online`، واختار الخطة **Free**.
3. Cloudflare هيقرا السجلات من Hostinger لوحده. راجعها كده:
   | السجل | القيمة | السحابة البرتقالي (Proxy) |
   |---|---|---|
   | `A` باسم `@` | `45.13.232.30` | **شغالة** (برتقالي) |
   | `A` باسم `www` | `45.13.232.30` | **شغالة** (برتقالي) |
   | `A` باسم `maps` | `13.140.141.32` | **مقفولة** (رمادي) |
   | `MX` وأي سجل `TXT` (SPF وDKIM وDMARC) | زي ما هي | رمادي (السجلات دي مالهاش سحابة) |
   - لو فيه سجل `mail` أو أي حاجة للإيميل نوعها `A`، خليها **رمادي**، وإلا الإيميل يقف.
4. عدّل سجل SPF (الـ `TXT` اللي أوله `v=spf1`) يبقى بالظبط:
   `v=spf1 a mx ip4:45.13.232.30 ip4:13.140.141.32 -all`
   عشان لو السيرفر التاني خد المكان، الإيميلات اللي بتطلع منه ما تروحش للسبام.
5. Cloudflare هيديك **اسمين nameservers** (زي `xxx.ns.cloudflare.com`). ادخل Hostinger: **Domains ← my-lawyer.online ← DNS / Nameservers ← Change nameservers**، وحط الاسمين دول مكان القدام واحفظ.
6. استنى إيميل من Cloudflare إن الدومين بقى **Active** (من دقايق لساعات).
7. في Cloudflare، الإعدادات دي:
   - **SSL/TLS ← Overview:** اختار **Full (strict)**.
   - **SSL/TLS ← Edge Certificates:** شغّل **Always Use HTTPS**، و**Minimum TLS Version** خليها **1.2**.
   - **Speed ← Optimization:** شغّل **Brotli** لو موجودة، و**HTTP/3**.
   - **Caching ← Cache Rules ← Create rule:** الاسم «صور الخريطة»، الشرط **URI Path starts with** `/map/t/`، والنتيجة **Eligible for cache**، و**Edge TTL** = 30 يوم.
   - **Security ← WAF:** شغّل **Managed rules** المجانية لو ظاهرة.
   - **Network:** خلّي **WebSockets** شغالة (مش بنستخدمها دلوقتي، بس ما تضرش).
8. **Token للتحويل التلقائي:** **My Profile ← API Tokens ← Create Token ← Edit zone DNS**، والـ Zone تختار `my-lawyer.online` بس، وبعدين **Create**. انسخ الـ token وحطه على اللابتوب في ملف جديد `D:\KAREM\.access\cloudflare-token.txt` (سطر واحد). كمان انسخ **Zone ID** من صفحة **Overview** للدومين (على اليمين تحت) وحطه في سطر تاني في نفس الملف.
9. قول لـ Claude «Cloudflare اتربط»، وهو يكمّل الباقي على السيرفرين (القسم 3).

## 3. اللي Claude بيعمله بعد الربط (محتاج «ارفع»)
- يحط الـ token على السيرفر التاني بس، فأمر التحويل (`take-over.sh`) يغيّر `@` و`www` للسيرفر التاني لوحده في ثواني.
- يقفل 80 و443 على السيرفرين إلا لـ Cloudflare، عشان محدش يوصل للسيرفر مباشرة من غيره.
- يتأكد إن عناوين الناس الحقيقية بتوصل الخادم (حدود الطلبات بتعتمد عليها). ده متجهز من دلوقتي (`/etc/nginx/conf.d/cloudflare-real-ip.conf`).
- يجرّب: الموقع، واللوحة، والدخول، والخط المباشر للتطبيق، والخريطة، وتجديد الشهادة.

## 4. ليه مش Load Balancing المدفوع
Cloudflare عنده خدمة بتبدّل بين السيرفرين لوحدها (حوالي 5 دولار في الشهر). مش محتاجينها دلوقتي: السيرفر التاني ما ينفعش يستقبل الكتابة غير بعد أمر التحويل، لأن القاعدة الأساسية على الأول، والتحويل الأوتوماتيك الكامل مع سيرفرين بس ممكن يعمل قاعدتين أساسيتين. أمر التحويل مع الـ token بيعمل نفس النتيجة ببلاش وبأمان.
