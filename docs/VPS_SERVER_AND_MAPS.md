## 2. الوضع الحالي الفعلي لمنظومة الخرائط على الـ VPS (Current Map Architecture)

بعد فحص السيرفر المباشر، وجدنا بيئة خرائط وملاحة ذاتية الاستضافة (Self-Hosted) متقدمة جداً ومبنية بواسطة Docker و Nginx:

```text
[الإنترنت / التطبيق]
         │ (Port 80 / 443)
         ▼
    ┌──────────┐
    │  Nginx   │ (Reverse Proxy + CORS + Caching)
    └────┬─────┘
         ├───────────────┬───────────────┐
         ▼               ▼               ▼
   / (Web Dashboard)  /osrm/          /tiles/
   /var/www/mylawyer  (Port 5000)     (Port 3000)
                      ┌─────────────┐ ┌────────────────┐
                      │ mylawyer-   │ │ mylawyer-      │
                      │ osrm        │ │ tileserver     │
                      │ (C++ OSRM)  │ │ (TileServer GL)│
                      └─────────────┘ └────────────────┘
```

### الحاويات النشطة حالياً (Active Containers):

1. **حاوية محرك التوجيه والملاحة (`mylawyer-osrm`):**
   - **الصورة:** `ghcr.io/project-osrm/osrm-backend`
   - **المنفذ الداخلي:** `5000` ⬅️ ممرر عبر Nginx في المسار: `https://my-lawyer.online/osrm/`
   - **الحالة:** شغال ومفعل 100% (Up & Healthy).
   - **البيانات المحملة:** شبكة طرق جمهورية مصر العربية كاملة ومخصصة للمركبات (`driving`).
   - **نتيجة الفحص الفعلي:** تم حساب مسار بين وسط القاهرة والمعادي (11.6 كم) في **أقل من 10 مللي ثانية**!

2. **حاوية خادم بلاطات الخريطة (`mylawyer-tileserver`):**
   - **الصورة:** `maptiler/tileserver-gl`
   - **المنفذ الداخلي:** `3000` ⬅️ ممرر عبر Nginx في المسار: `http://13.140.141.32/tiles/`
   - **الحالة:** شغال ومفعل 100% (Up & Healthy).
   - **البيانات المحملة:** خريطة مصر بصيغة الفيكتور الحديثة **PMTiles** (`Protomaps Basemap`) تغطي كامل حدود مصر (`[24.5, 21.8, 37.1, 31.9]`) بزووم كامل حتى مستوى 15.
   - **دعم اللغة العربية:** يتضمن أسماء الشوارع والمدن والأحياء بالعربية (`name:ar`).

## 3. التقييم الفني والرأي الهندسي (Expert Evaluation)

### هل نستخدم خادم الخرائط هذا في التطبيق؟
**نعم وبقوة، هذا القرار ممتاز بنسبة 100% للأسباب التالية:**

1. **صفر تكاليف تشغيل (Zero Google Maps Bills):**
   - خرائط جوجل تكلف مبالغ طائلة عند التوسع (تصل لآلاف الدولارات شهرياً عند كثرة طلبات الـ Routing والخرائط).
   - خادمك الخاص على الـ VPS يدعم ملايين الطلبات الشهرية **بتكلفة اشتراك السيرفر الثابتة فقط (~15-30$ شهرياً)**.
2. **استقلالية تامة وسرعة فائقة:**
   - السيرفر في ألمانيا قريب جداً من مصر (زمن استجابة الشبكة ~84ms، وحساب المسار OSRM يستغرق 5-10ms).
   - لا توجد أي قيود استخدام (Rate Limits) أو حظر مثل الخوادم العامة المجانية.
3. **تغطية شاملة ومحدثة لمصر:**
   - ملف الخريطة مبني حديثاً من بيانات OpenStreetMap الرسمية لشوارع ومحافظات مصر بالكامل.

## 4. خطة التكامل مع تطبيق Flutter (Integration Strategy)

### المرحلة الأولى (جاهزة ومفعلة فوراً):
- **حساب المسافة والوقت لخدمة «محاميك حالاً» عبر OSRM الخاص بك:**
  - عند طلب خدمة «محاميك حالاً»، يستدعي التطبيق محرك OSRM على خادمك:
    ```http
    GET https://my-lawyer.online/osrm/route/v1/driving/{lng1},{lat1};{lng2},{lat2}?overview=false
    ```
  - الرد لحظي يعطي المسافة الدقيقة بالمتر وزمن وصول المحامي بالثانية.

### المرحلة الثانية (عرض بلاطات الخريطة):
- الخادم يقدم بلاطات فيكتور `pbf` عبر `TileServer GL`.
- يمكننا إما:
  1. إضافة ستايل راستر خفيف (Raster Style) على `TileServer GL` بالسيرفر ليولد صور PNG مباشرة لـ `flutter_map`.
  2. أو ربط `TileLayer` مع بروكسي البلاطات على الـ VPS مع الاحتفاظ بـ CartoDB كبديل احتياطي (Fallback).
