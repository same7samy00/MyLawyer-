# ملخص المشروع

**آخر تحقق:** 2026-11-07. ملف ثابت نسبيًا: بيتغير لما المنتج أو البنية الكبيرة تتغير. الحالة اليومية في [`CURRENT_STATUS.md`](CURRENT_STATUS.md).

## إيه هو My Lawyer؟
منصة قانونية مصرية بتربط **الموكل** بـ**المحامي**، بالعامية المصرية ومن اليمين للشمال. تطبيق واحد للاتنين (`com.mylawyer.my_lawyer`)، ولوحة تحكم للإدارة، وموقع عام.

## الخدمات
| الخدمة | إزاي بتشتغل | الحالة |
|---|---|---|
| **محاميك حالاً** | الموكل يطلب عروض أسعار، والطلب بيروح لأقرب محامين متاحين في جولات، والموكل يختار ويدفع، والمحامي يروحله، والمكان الدقيق بيظهر بعد الدفع بس | شغالة |
| **استشارة سريعة** | الموكل يكتب المشكلة أو يصوّر ورقه ويدفع، والإدارة تكلمه | شغالة |
| خدمات تانية (عقود، شركات، قضايا) | معروضة كخدمات | لسه |

## الفلوس باختصار
دفتر حسابات من غير أرصدة متخزنة: رصيد الموكل وأتعاب المحامي محسوبين من الحركات. أتعاب المحامي بتتحجز 24 ساعة بعد إنهاء المهمة. العمولة 30% والضريبة 0% دلوقتي. **مفيش بوابة دفع ولا سحب حقيقي لسه.** التفاصيل في `docs/engineering/SYSTEM_MAP.md` القسم 6.
