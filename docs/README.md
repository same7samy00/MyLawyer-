# التوثيق

كل ملف بيوصف الوضع الحالي بس، والتاريخ في Git (`git log`). اللي لسه هيتعمل في `NEXT.md` لوحده.

## مين مصدر الحقيقة
| نوع المعلومة | مكانها الوحيد |
|---|---|
| إيه شغال دلوقتي واتأكدنا منه | `CURRENT_STATE.md` وملف الموضوع، وفوق كل ملف **«آخر تحقق»** بالتاريخ وطريقة التأكد |
| اللي ما اتجربش أو ما اتأكدش، والمشاكل المعروفة | `KNOWN_ISSUES.md` |
| قرار صاحب المشروع الساري | `DECISIONS.md` (الجديد بيتكتب مكان القديم) |
| متقرر ولسه ما اتعملش | `NEXT.md` |
| مستني قرار | `KNOWN_ISSUES.md` القسم 5 |
| إيه اللي اتغير وإمتى وليه | `git log` (رسالة كل commit بتقول إيه وليه) |

**لو التوثيق مختلف عن الكود أو السيرفر، الكود والسيرفر هما الصح**: اتأكد، وصلّح التوثيق في نفس الـ commit. معلومة واحدة ما تتكتبش في ملفين: ملف واحد يشرحها والباقي يشاور عليه.
