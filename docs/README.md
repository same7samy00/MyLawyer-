# التوثيق

| لو سؤالك عن... | اقرا |
|---|---|
| الوضع دلوقتي: إيه شغال، وفين، والمفتوح قبل الإطلاق، والتشغيل والبناء | `CURRENT_STATE.md` |
| قواعد العمل: الشكل، والاختبارات، والحفظ، والرفع | `WORK_RULES.md` |
| قرارات صاحب المشروع (فلوس، خدمة، شكل، إطلاق) | `DECISIONS.md` |
| الخطة الجاية: الخدمات السبعة، وحذف الحساب، واللي لسه ما اتعملش | `NEXT.md` |
| «محاميك حالاً»: الرحلة والقواعد وصفحة الطلبات | `URGENT_SERVICE.md` |
| الخريطة والموقع | `GPS_SYSTEM.md` |
| طبقات التطبيق ولوحة التحكم | `ARCHITECTURE.md` |
| مسارات الخادم | `API_DOCUMENTATION.md` |
| قاعدة البيانات (و`backend/migrations` هو المرجع) | `DATABASE_ARCHITECTURE.md` |
| السيرفرين والخدمات اللي عليهم | `SERVER_ARCHITECTURE.md` |
| الرفع والرجوع | `DEPLOYMENT.md` |
| النسخ الاحتياطية والاسترجاع | `BACKUP_AND_RECOVERY.md` |
| المراقبة والسجلات | `MONITORING.md` |
| الأسرار والحماية | `SECURITY.md` |
| GitHub والسيرفر وبيانات الدخول (من غير أسرار) | `ACCESS.md` |
