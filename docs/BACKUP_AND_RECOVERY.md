## 2. المطلوب (مستني موافقة صاحب المشروع)
1. نسخة يومية للقاعدة على الجديد الساعة 3:30 الصبح، وتتمسح بعد 14 يوم.
2. نسخة يومية لـ `storage` بنفس الطريقة.
3. نسخة بره السيرفر (Google Drive أو Object Storage).
4. تجربة استرجاع فعلية في قاعدة مؤقتة مرة كل شهر.

## 3. الاسترجاع (القاعدة)
بيمسح البيانات الحالية، فمحتاج موافقة صريحة، ونسخة جديدة قبله.
```bash
# على السيرفر الجديد: وقف الخادم، ورجّع النسخة، وشغّله
systemctl stop mylawyer-backend
DB=$(grep ^DATABASE_URL= /var/www/mylawyer/backend/.env | cut -d= -f2-)
gunzip -c /root/mylawyer-backups/<الملف>.sql.gz | psql "$DB"
systemctl start mylawyer-backend
```
النسخ اللي من `pg_dump` العادي نص SQL؛ استرجعها في قاعدة فاضية. ونسخة النقل `from-old-server.dump` بصيغة `pg_restore`.

## 4. لو السيرفر الجديد وقع خالص
1. سيرفر جديد بنفس الخطوات اللي في `SERVER_ARCHITECTURE.md`.
2. آخر نسخة قاعدة بره السيرفر (لما تبقى موجودة).
3. تحويل `@` في Hostinger للعنوان الجديد.
4. runner جديد (`ACCESS.md`).
