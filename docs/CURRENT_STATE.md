# الوضع الحالي

**اتراجع على الكود والسيرفرين يوم 2026-11-10.** الملف ده بيوصف اللي شغال دلوقتي بس. أي تغيير في المشروع يتعدل هنا في نفس الـ commit.

## 1. المنتج
منصة قانونية لمصر، تطبيق واحد للموكل والمحامي، ولوحة تحكم للإدارة، وموقع عام. **في التطوير، ومفيش مستخدمين حقيقيين.**

| الخدمة | الوضع |
|---|---|
| «محاميك حالاً» | شغالة: الموكل يطلب لنفسه، وأقرب المحامين بوقت الطريق يبعتوا أسعار، ويختار ويدفع خلال 10 دقايق، والمحامي يوصل وينهي. القواعد في `URGENT_SERVICE.md` |
| «استشارة سريعة» | شغالة: استشارة بالتليفون أو باطلاع على ورق، والفريق بيتابعها من اللوحة |
| المحفظة والتقييمات والدعم الفني والإشعارات | شغالين |
| الدفع | **تأكيد تجريبي من غير بوابة دفع حقيقية** |

صفحة الطلبات فيها كل الطلبات من كل الخدمات بكارت واحد (`OrderCard`) للموكل والمحامي.

## 5. التشغيل والبناء
| المطلوب | الأمر |
|---|---|
| تشغيل التطبيق على جهاز | `flutter run -d <الجهاز>` |
| نسخة التثبيت (واحدة بس، للموكل والمحامي) | `flutter build apk --release` ثم `adb -s <الجهاز> install -r build/app/outputs/flutter-apk/app-release.apk` |
| نسخة المتجر | `flutter build appbundle --release` |
| معاينة اللوحة محليًا | `cd backend && npm run preview:panel` ثم `http://127.0.0.1:3900/api/v1/admin-panel` |
| فحص التطبيق | `flutter analyze` و`flutter test` (خادم وهمي محلي، ما بيكلمش الإنتاج) |
| فحص الخادم | `cd backend && npx tsc --noEmit && npm test` (قاعدة جوه الذاكرة) |

- Flutter 3.24.3 في `C:\src\flutter\bin\flutter.bat`.
- توقيع الإنتاج: `android/mylawyer-release.jks` و`android/key.properties` (بره Git). ضياعهم يمنع تحديث التطبيق.
- اختبار جديد للخادم لازم يتضاف لسكريبت `test` في `backend/package.json`.
- **موقع المحاكي:** `adb -s emulator-5554 shell appops set com.android.shell MOCK_LOCATION allow`، وبعدين لكل واحد من `gps` و`fused` و`network`: `cmd location providers add-test-provider <p>`، و`set-test-provider-enabled <p> true`، و`set-test-provider-location <p> --location <lat>,<lon> --accuracy 5` متكرر كل ثانيتين. ما تكتبش إحداثيات صاحب المشروع في أي ملف.
