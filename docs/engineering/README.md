## علامات التحقق

| العلامة | معناها |
|---|---|
| **VERIFIED** | اتأكدت منه بقراءة الكود نفسه |
| **RUNTIME VERIFIED** | اتأكدت منه بتشغيل فعلي (اختبار أو أمر على السيرفر) |
| **PARTIALLY VERIFIED** | الكود موجود بس السلوك كله ما اتجربش |
| **UNVERIFIED** | مفيش دليل كفاية |
| **NOT IMPLEMENTED** | دورت في الأماكن المتوقعة وما لقيتوش |
| **DEPRECATED** | قديم ومتساب لسبب معروف |

## تكمل منين

1. اقرا `FINDINGS.md`. المشاكل اللي حالتها «مستني قرار» محتاجة صاحب المشروع، لأن أغلبها في منطق الفلوس، و`AGENTS.md` بيمنع تعديله من غير موافقة صريحة.
2. أي إصلاح يبقى على فرع لوحده، ويتضاف له اختبار في `backend/tests` يثبت المشكلة قبل الإصلاح.
3. حدّث حالة المشكلة في `FINDINGS.md` في نفس الـ commit.
