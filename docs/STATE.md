## 6. حاجات ما تتنسيش
- ممنوع push أو رفع أو تعديل على السيرفر غير لما صاحب المشروع يقول «ارفع». وممنوع تطلب منه توكن أو بيانات: كله في `.access/` (`docs/ACCESS.md`).
- منطق الفلوس والتصميم العام ومسح البيانات محتاجين موافقة صريحة.
- الريبو **عام**، فاتأكد قبل كل commit إن مفيش حاجة من `.access/` أو أي سر في الملفات.
- إحصائيات قاعدة الإنتاج ما اتقرتش، لأن أداة الحماية في Claude Code رفضت الاستعلام.
